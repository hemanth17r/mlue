# MLUE Specification — Phase 0.2

## 1. Overview & Objective
MLUE Phase 0.2 extends the minimal machine-oriented computational representation from Phase 0.1 to establish:
1. **Generalized 2D Geometry**: Support for axis-aligned rectangular bounds (`box`) alongside radial bounds (`circle`).
2. **Time Evolution ($\Delta t$) & Velocity**: Representation of linear velocity vectors $\vec{v} = (v_x, v_y)$ in normalized units per second.
3. **Deterministic State Evolution & Boundary Constraints**: A formal mathematical contract for updating entity positions over discrete time steps $\Delta t$ and resolving environment boundary reflection.
4. **Multi-Entity Composition**: Composing multiple heterogeneous entities within a single environment.

---

## 2. MLUE Representation Schema (Version `0.2`)

The Phase 0.2 MLUE format uses a JSON-encoded data structure with the following schema:

```json
{
  "mlue_version": "0.2",
  "environment": {
    "dimensions": [600, 400],
    "background": "#0F172A"
  },
  "entities": [
    {
      "id": "ball_01",
      "type": "circle",
      "position": {
        "x": 0.5,
        "y": 0.5
      },
      "size": {
        "radius": 0.05
      },
      "velocity": {
        "vx": 0.3,
        "vy": 0.2
      },
      "properties": {
        "color": "#38BDF8"
      }
    },
    {
      "id": "paddle_left",
      "type": "box",
      "position": {
        "x": 0.08,
        "y": 0.5
      },
      "size": {
        "width": 0.03,
        "height": 0.25
      },
      "velocity": {
        "vx": 0.0,
        "vy": 0.15
      },
      "properties": {
        "color": "#F43F5E"
      }
    }
  ]
}
```

### Fields:
* `mlue_version` *(string, required)*: Must be `"0.2"` (or `"0.1"` for backward compatibility).
* `environment` *(object, optional)*:
  * `dimensions` *(array of 2 positive integers [width, height])*: Resolution bounds for viewport.
  * `background` *(string)*: Hex color code (e.g. `"#0F172A"`).
* `entities` *(array of objects, required, non-empty)*:
  * `id` *(string, required)*: Unique identifier for the entity.
  * `type` *(string, required)*: `"circle"` or `"box"`.
  * `position` *(object, required)*:
    * `x` *(number in [0.0, 1.0])*: Normalized horizontal center.
    * `y` *(number in [0.0, 1.0])*: Normalized vertical center.
  * `size` *(object, required)*:
    * For `circle`: `radius` *(number in (0.0, 0.5])*: Normalized radius relative to $\min(\text{width}, \text{height})$.
    * For `box`: `width` *(number in (0.0, 1.0])*, `height` *(number in (0.0, 1.0])*: Normalized width and height relative to environment width and height.
  * `velocity` *(object, optional)*:
    * `vx` *(number)*: Horizontal normalized displacement per second.
    * `vy` *(number)*: Vertical normalized displacement per second.
    * Default is `{"vx": 0.0, "vy": 0.0}`.
  * `properties` *(object, optional)*:
    * `color` *(string)*: Hex color code for presentation fill.

## 3. Mathematical Evaluation & Time-Evolution Contract

### 3.1 Space Projection
For an environment with width $W$ and height $H$:
* **Circle**:
  * Horizontal radius extent in normalized space: $r_x = r \cdot \frac{\min(W, H)}{W}$
  * Vertical radius extent in normalized space: $r_y = r \cdot \frac{\min(W, H)}{H}$
  * Concrete center: $(c_x, c_y) = (x \cdot W, y \cdot H)$
  * Concrete bounding box: $(c_x - r \cdot \min(W, H), c_y - r \cdot \min(W, H), c_x + r \cdot \min(W, H), c_y + r \cdot \min(W, H))$
* **Box**:
  * Normalized half-extents: $h_w = \frac{\text{width}}{2}$, $h_h = \frac{\text{height}}{2}$
  * Concrete center: $(c_x, c_y) = (x \cdot W, y \cdot H)$
  * Concrete bounding box: $((x - h_w) \cdot W, (y - h_h) \cdot H, (x + h_w) \cdot W, (y + h_h) \cdot H)$

### 3.2 Time-Step Integration ($\Delta t$)
For discrete simulation step $\Delta t$:
$$x_{\text{new}} = x + v_x \cdot \Delta t$$
$$y_{\text{new}} = y + v_y \cdot \Delta t$$

### 3.3 Boundary Constraint & Reflection
When an entity reaches the normalized environment bounds $[0.0, 1.0]$:
* **Horizontal Axis**:
  * Let horizontal half-extent be $e_x$ ($r_x$ for circle, $h_w$ for box).
  * If $x_{\text{new}} - e_x \le 0.0$: $x_{\text{new}} = e_x$, $v_x = -v_x$
  * If $x_{\text{new}} + e_x \ge 1.0$: $x_{\text{new}} = 1.0 - e_x$, $v_x = -v_x$
* **Vertical Axis**:
  * Let vertical half-extent be $e_y$ ($r_y$ for circle, $h_h$ for box).
  * If $y_{\text{new}} - e_y \le 0.0$: $y_{\text{new}} = e_y$, $v_y = -v_y$
  * If $y_{\text{new}} + e_y \ge 1.0$: $y_{\text{new}} = 1.0 - e_y$, $v_y = -v_y$
