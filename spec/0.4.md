# MLUE Specification — Phase 0.4

## 1. Overview & Objective
MLUE Phase 0.4 introduces **Input Signals** as a universal state-modulation primitive.

In conventional architectures, input is tightly coupled to human hardware devices (keyboards, mice, OS event loops). In MLUE, an input is fundamentally an **external normalized control signal $u \in [-1.0, 1.0]$ mapped to an entity channel**, completely agnostic of whether the source is a human keypress, an AI action vector, or a deterministic test script.

---

## 2. MLUE Representation Schema (Version `0.4`)

```json
{
  "mlue_version": "0.4",
  "environment": {
    "dimensions": [700, 450],
    "background": "#0F172A"
  },
  "entities": [
    {
      "id": "paddle_left",
      "type": "box",
      "position": {
        "x": 0.05,
        "y": 0.5
      },
      "size": {
        "width": 0.025,
        "height": 0.3
      },
      "properties": {
        "color": "#F43F5E",
        "solid": true,
        "control": {
          "channel": "player_left",
          "axis": "y",
          "speed": 0.5
        }
      }
    }
  ]
}
```

### Entity Properties Added in 0.4:
* `properties.control` *(object, optional)*:
  * `channel` *(string, required)*: Identifier for the input signal channel (e.g. `"player_left"`, `"player_right"`).
  * `axis` *(string, required)*: Axis to modulate (`"x"` or `"y"`).
  * `speed` *(number, positive, required)*: Maximum velocity magnitude in normalized units per second at signal $= \pm 1.0$.

---

## 3. Mathematical Evaluation Contract

Given an input signal vector $\vec{u} = \{ \text{channel}_k: u_k \mid u_k \in [-1.0, 1.0] \}$ passed into the evaluation step:

1. **Velocity Modulation**:
   For each entity with a valid `control` property:
   $$v_{\text{axis}} = \text{clamp}(u_{\text{channel}}, -1.0, 1.0) \times \text{speed}$$
2. **Motion Integration & Boundary Clamping**:
   The entity advances by $p' = p + v \cdot \Delta t$ and is clamped to environment boundaries $[0.0, 1.0]$ according to its half-extents.
3. **Collision & Solid Interaction**:
   Controlled entities participate in pairwise solid collisions as defined in Phase 0.3.
