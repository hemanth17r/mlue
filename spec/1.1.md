# MLUE Specification — Phase 1.1

## 1. Overview & Objective

MLUE Phase 1.1 upgrades the declarative document state from a flat key-value map into a **hierarchical in-memory document database**.

In Phase 0, `state_variables` was restricted to top-level scalar primitives (`"score": 0`, `"lives": 3`). In Phase 1.1, MLUE introduces:
1. **Nested Hierarchical Data**: First-class support for nested JSON objects, lists, strings, booleans, and numeric values inside `state_variables`.
2. **Deterministic Keypath Navigation**: Universal dot-path and bracket syntax (`a.b[0].c`) for addressing, querying, and mutating nested nodes.
3. **5 Atomic Mutation Actions**:
   * `"set_path"`: Assign any value to an addressed keypath.
   * `"increment_path"`: Atomically add/subtract a numeric delta to an addressed numeric keypath.
   * `"push"`: Append an item to an addressed array.
   * `"pop"`: Remove an item by index from an addressed array.
   * `"delete_key"`: Remove a key from an addressed object map.
4. **Path-Based Condition Triggers**: Evaluating rules against nested properties and collection metadata (e.g. `inventory.length >= 3`).
5. **Static Path Provability**: Compile-time static verification in `loader.py` to reject malformed paths, out-of-bounds initial array indices, and type mismatches.

## 3. Keypath Grammar & Resolution Rules

A **keypath** is an ASCII string defining a deterministic navigation sequence from the root `state_variables` dictionary:

### 3.1 Path Syntax
* **Object Keys**: Alphanumeric strings delimited by dots `.`, e.g. `session.stats.energy`.
* **Array Indices**: Non-negative integers enclosed in square brackets `[i]`, e.g. `inventory[0].durability`.
* **Mixed Sequences**: Arbitrary nesting of keys and indices, e.g. `teams[1].roster[0].stats.attack`.
* **Array Length Property**: Addressing `.length` on any list returns its current integer item count, e.g. `inventory.length`.

### 3.2 Resolution Semantics
1. If any key does not exist in a map during runtime resolution, or if an array index is out of bounds:
   * **For Condition Evaluation**: Resolves to `None`, evaluating conditions safely to `False` (zero runtime exceptions).
   * **For Actions**: Actions targeting unreachable paths are safely skipped and logged without crashing the deterministic step loop.
2. Negative array indices (e.g. `[-1]`) are supported in `pop` to refer to the last item in a list.

## 4. Atomic Mutation Actions Reference

| Action | Required Fields | Optional Fields | Description |
| :--- | :--- | :--- | :--- |
| `set_path` | `target`: path string, `value`: any | None | Assigns `value` to the exact keypath, replacing existing value or creating key if in map. |
| `increment_path` | `target`: path string | `amount`: float/int (default 1.0) | Adds numeric `amount` to target path. If target is non-numeric, action is skipped. |
| `push` | `target`: array path string, `value`: any | None | Appends `value` to the array located at `target`. If target is not a list, action is skipped. |
| `pop` | `target`: array path string | `index`: int (default -1) | Removes and discards element at `index` from target array. If index is out of bounds, action is skipped. |
| `delete_key` | `target`: object path string | `key`: string *(or target ends in key)* | Deletes named key from target dictionary. |

---

## 5. Backward Compatibility Invariants

* **Version Range**: `1.1` loaders support all documents from versions `0.1` through `1.1`.
* **Legacy Actions**: Legacy `set` and `increment` targeting top-level `state_variables` keys remain 100% valid and map directly to `set_path` and `increment_path`.
* **Legacy Conditions**: `condition.state_variable` continues to evaluate top-level keys identically to `condition.state_path`.
