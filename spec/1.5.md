# MLUE Specification 1.5: Native C Execution Core (C-ABI & Memory Layout)

## Status: APPROVED & FROZEN
## Schema Version: 1.5
## Substrate Tier: Tier L0 (Native Compiled Hardware Execution)
## Language Standard: Pure ANSI C99 / C11 (Zero External Dependencies)

---

## 1. Executive Overview

Subphase 1.5 transitions the MLUE simulation engine to a pure, native C execution kernel (`mlue_core.c`). By laying out entities in fixed-size, 64-byte contiguous memory buffers and executing continuous time integration, arena boundary clamping, spatial broadphase pairing, and pairwise impulse physics in compiled native C, MLUE achieves sub-microsecond evaluation latency ($< 5\,\mu\text{s}$ per step, $> 200,000\text{ ticks/s}$).

---

## 2. Memory Layout & C-ABI Data Structures

All C-ABI structs are Little-Endian with explicit byte packing to match the binary `.mlueb` document format exactly.

### 2.1 Entity Record Struct (64 Bytes, Fixed-Size)
```c
#pragma pack(push, 1)
typedef struct {
    uint32_t id_idx;           /* 0x00: Offset into string dictionary */
    uint32_t color_rgba;       /* 0x04: Packed 32-bit RGBA integer */
    uint8_t  entity_type;      /* 0x08: 1 = circle, 2 = box */
    uint8_t  flags;            /* 0x09: bit 0: solid, bit 1: active, bit 2: controlled */
    uint8_t  ctrl_axis;        /* 0x0A: 0 = none, 1 = x, 2 = y */
    uint8_t  reserved_1;       /* 0x0B: 8-bit alignment padding */
    uint32_t ctrl_channel_idx; /* 0x0C: Offset into string dictionary for control channel */
    double   pos_x;            /* 0x10: Normalized X position [0.0, 1.0] */
    double   pos_y;            /* 0x18: Normalized Y position [0.0, 1.0] */
    double   vel_vx;           /* 0x20: Normalized X velocity */
    double   vel_vy;           /* 0x28: Normalized Y velocity */
    double   size_p1;          /* 0x30: Radius (circle) or Width (box) */
    double   size_p2;          /* 0x38: Height (box) or 0.0 (circle) */
} MLUE_EntityRecord;
#pragma pack(pop)
```
* **Invariant**: `sizeof(MLUE_EntityRecord) == 64` bytes.

### 2.2 Environment Struct (16 Bytes)
```c
#pragma pack(push, 1)
typedef struct {
    uint32_t width;       /* Environment viewport width in pixels */
    uint32_t height;      /* Environment viewport height in pixels */
    uint32_t bg_rgba;     /* Background color packed as 32-bit RGBA integer */
    uint32_t reserved_0;  /* Alignment padding */
} MLUE_Environment;
#pragma pack(pop)
```
* **Invariant**: `sizeof(MLUE_Environment) == 16` bytes.

### 2.3 Step Result Struct
```c
#pragma pack(push, 1)
typedef struct {
    uint32_t num_active_entities;
    uint32_t num_collision_events;
    uint32_t candidate_pairs_checked;
    uint32_t status_flags;  /* 0 = OK, non-zero = error */
} MLUE_StepResult;
#pragma pack(pop)
```

## 3. Exported C-ABI Function Signatures

All exported functions use standard C calling conventions (`cdecl` / `stdcall` on Windows) with explicit cross-platform visibility macros (`MLUE_API`):

```c
#if defined(_WIN32) || defined(__CYGWIN__)
  #define MLUE_API __declspec(dllexport)
#else
  #define MLUE_API __attribute__((visibility("default")))
#endif
```

### 3.1 Version Discovery
```c
MLUE_API uint32_t mlue_core_version(void);
/* Returns packed version integer: (MAJOR << 16) | (MINOR << 8) | PATCH */
```

### 3.2 Time Integration & Physics Step
```c
MLUE_API MLUE_StepResult mlue_core_step(
    MLUE_EntityRecord* entities,
    uint32_t num_entities,
    const MLUE_Environment* env,
    double dt
);
```

```c
MLUE_API MLUE_StepResult mlue_core_step_fixed(

```

## 4. Zero Dynamic Memory Allocation Guarantee (DO-178C)

To guarantee hard real-time execution and eliminate memory fragmentation:
* `mlue_core_step` operates entirely in-place on caller-allocated contiguous buffers (`entities`).
* Scratch buffers for spatial hashing and broadphase pair candidates use bounded, stack-allocated or pre-sized contiguous arena memory.
* **$0\text{ malloc()}$ / $0\text{ free()}$ calls are made inside the simulation step loop**.
