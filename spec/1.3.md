# MLUE Specification 1.3: Continuous Spatial Indexing & Broadphase Acceleration

## 1. Executive Overview

In physical simulations and interactive software containing $N$ entities, testing every entity against every other entity results in $O(N^2)$ algorithmic complexity ($\frac{N(N-1)}{2}$ pairwise collision tests).
* For $N = 10$, $\frac{10 \times 9}{2} = 45$ checks per step (negligible).
* For $N = 1,000$, $\frac{1000 \times 999}{2} = 499,500$ checks per step (causes severe frame drops and latency spikes).

MLUE 1.3 introduces a two-tier collision pipeline:
1. **Broadphase Spatial Indexing ($O(N \log N)$ or $O(N)$ amortized)**: Uses 2D Axis-Aligned Bounding Boxes (AABBs) mapped into a **Dynamic Uniform Spatial Hash Grid** and **Bounding Volume Hierarchy (BVH)** to prune non-colliding entity pairs.
2. **Narrowphase Exact Physics ($O(K)$ where $K \ll N^2$)**: Executes exact continuous geometric impulse solvers (circle-circle, box-box, circle-box) only on broadphase candidate pairs that have overlapping bounding boxes.

## 2. Mathematical Definition of 2D Normalized AABBs

Every entity $E$ with position $\mathbf{p} = (x, y) \in [0.0, 1.0]^2$ is bounded by a tight Axis-Aligned Bounding Box (AABB) defined by its minimum and maximum normalized coordinates:

$$\text{AABB}(E) = [x_{\min}, y_{\min}, x_{\max}, y_{\max}]$$

### 2.1 Circle Geometry Half-Extents
For an entity of type `circle` with radius $r$ in environment dimensions $(W, H)$:
$$e_x = r \cdot \frac{\min(W, H)}{W}, \quad e_y = r \cdot \frac{\min(W, H)}{H}$$
$$x_{\min} = x - e_x, \quad x_{\max} = x + e_x$$
$$y_{\min} = y - e_y, \quad y_{\max} = y + e_y$$

### 2.2 Box Geometry Half-Extents
For an entity of type `box` with normalized width $w$ and height $h$:
$$e_x = \frac{w}{2.0}, \quad e_y = \frac{h}{2.0}$$
$$x_{\min} = x - e_x, \quad x_{\max} = x + e_x$$
$$y_{\min} = y - e_y, \quad y_{\max} = y + e_y$$

### 2.3 AABB Overlap Condition
Two bounding boxes $A$ and $B$ overlap if and only if:
$$\text{Overlap}(A, B) \iff (A.x_{\min} \le B.x_{\max}) \land (A.x_{\max} \ge B.x_{\min}) \land (A.y_{\min} \le B.y_{\max}) \land (A.y_{\max} \ge B.y_{\min})$$

## 3. Spatial Hash Grid Specification (`SpatialHashGrid2D`)

### 3.1 Cell Sizing & Grid Parameters
The spatial grid partitions the normalized $[0.0, 1.0]^2$ arena into discrete square cells of size $\Delta_{cell}$:
$$\Delta_{cell} = \max\left(2 \cdot \max_{E}(e_x, e_y), 0.05\right)$$

### 3.2 Cell Coordinate Projection
For any continuous coordinate $(x, y)$, the cell indices $(C_x, C_y)$ are:
$$C_x = \lfloor x / \Delta_{cell} \rfloor, \quad C_y = \lfloor y / \Delta_{cell} \rfloor$$

### 3.3 Spatial Hash Function
To support unbounded or dynamic coordinates with $O(1)$ memory lookup:
$$\text{Hash}(C_x, C_y) = (C_x \cdot 73856093) \oplus (C_y \cdot 19349663)$$

### 3.4 Multi-Cell Insertion & Candidate Generation
1. For an entity $E_i$ with bounding box $[x_{\min}, y_{\min}, x_{\max}, y_{\max}]$, find min and max cell coordinates:
   $$C_{x,\min} = \lfloor x_{\min} / \Delta_{cell} \rfloor, \quad C_{x,\max} = \lfloor x_{\max} / \Delta_{cell} \rfloor$$
   $$C_{y,\min} = \lfloor y_{\min} / \Delta_{cell} \rfloor, \quad C_{y,\max} = \lfloor y_{\max} / \Delta_{cell} \rfloor$$
2. Insert entity index $i$ into all grid cells $(C_x, C_y)$ where $C_{x,\min} \le C_x \le C_{x,\max}$ and $C_{y,\min} \le C_y \le C_{y,\max}$.
3. Candidate extraction: For each cell with $> 1$ entity, generate pairs $(i, j)$ with $i < j$. Deduplicate pairs across cells using a set or canonical ordering.
4. **Broadphase Filter**: For each candidate pair $(i, j)$, evaluate $\text{Overlap}(\text{AABB}(E_i), \text{AABB}(E_j))$. Only pairs with overlapping AABBs are emitted to narrowphase.

## 4. Invariant Guarantees & Zero False-Negatives

* **Theorem (Zero False Negatives)**:
  If two entities $A$ and $B$ physically collide geometrically ($\text{Distance}(A, B) \le 0$), their continuous geometric shapes intersect. Since $\text{Shape}(A) \subseteq \text{AABB}(A)$ and $\text{Shape}(B) \subseteq \text{AABB}(B)$, $\text{AABB}(A) \cap \text{AABB}(B) \neq \emptyset$. Furthermore, any two overlapping AABBs must share at least one spatial grid cell. Therefore, the spatial hash grid is guaranteed to emit pair $(A, B)$ with **$0.0\%$ false-negative rate**.
* **Broadphase Cull Efficiency**:
  $$\text{Cull Efficiency} = 1.0 - \frac{\text{Candidate Pairs Emitted}}{\frac{N(N-1)}{2}} \ge 98.0\% \quad (\text{for } N = 1,000)$$
